# Seguridad

No publiques contraseñas, Client Secret, tokens, códigos de autorización, copias de seguridad de HA ni archivos de su almacenamiento.

Para reportar una vulnerabilidad, utiliza **Security → Report a vulnerability** en GitHub cuando esté habilitado. Si no está disponible, abre un issue solicitando un canal privado, sin detalles sensibles.

La integración consulta datos de compras mediante la API de Mercado Libre y guarda la autorización en Home Assistant. El acceso a HA y sus copias de seguridad debe protegerse.
